# Stall: b-roll inserts for a talking-head demo

## Intent
The user films a simple talking-head video from video/SCRIPT.md. This project renders the
motion b-roll that gets cut between face shots: animated chat screens showing a seller opening a shop
and a buyer finding, paying and getting a receipt, plus a price-drop alert, title cards and an end card.
Simulated UI only, no real money. Simple English.

## Assets
- None supplied yet. The face footage arrives later as one landscape phone take.

## Customizations
- Each scene renders as its own clip so the user (or I) can drop them into the edit.
